# AgMA-Difff
Agent-guided, mode-aware diffusion augmentation for class-imbalanced diabetic retinopathy grading on DDR. Includes a reproduction of the MICCAI 2025 class-conditioned diffusion baseline (SD1.5 + LoRA + ECC) and AgMA-Diff: RETFound mode discovery, mode-conditioned LoRA, three-gate verification, and an LLM/UCB augmentation agent.
